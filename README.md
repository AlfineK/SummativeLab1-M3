# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# Personal Project Showcase App

An app is created allowing users to see previous projects and add on new completed projects.It is built with React, Jsx together with tailwindcss,September 02/09/2026.

 By **Kinya Alfine**

## Overview

This app allows users to see projects that were previously created. On those projects you have a search button that filters the project you're searching for.Also on finishing a project you're currently working on,you get to add that project on the list of already completed projects.

## Requirements

- A modern web browser
- Internet

## **Using the App**

1. In the browser you'll find a list of finished project

2. If you want to search a particular project type the name of project you want: you'll get the project and if the project is not there you'll get a message saying the no projects found matching your search.

3. When adding a new project :type the title of the project and a brief description of what the project does.

4. If satisfied with the newproject then you can click *createNewProject* and the project will be added to the list of completed objects.

## Local Setup

### Run locally

 To run this locally you need a PC with the following

- A modern web browser
- Access to the internet
- GIT download the Ubuntu version
- npm
- Vite to install React
- Ubuntu
- node.js
- VS code

### Installation

1. Clone the repository on the *Ubuntu* terminal

```bash
git clone git@github.com:AlfineK/SummativeLab1-M3.git
```

2.The repository will be copied then run code to open the code on VScode

``` bash
code SummativeLab1-M3
```

3.After Vs code opens open the vscode terminal by pressing control and backtick together.

4.Run npm install to install all dependencies

```bash
npm install
```

5.Press enter,

6.Run npm run dev

```bash
npm run dev
```

7.Open the browser once it pops up.After you have opened the browser you'll see list of completed projects. You can search the project you want and add new completed objects.
